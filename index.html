Taguchi orthogonal array generator

This page tells you which tests to run when you want to find the best settings for a process. You enter the factors, which are the settings that you can change, and the levels, which are the values that you want to try. After you enter your test results, the page shows the best level of each factor.

Why few tests are enough

Testing every combination of 4 factors with 3 levels each takes 81 tests. A common shortcut is to start from one combination and change one factor at a time. That takes 9 tests, but most levels appear in only 1 test, so one measurement error can change your conclusion.

This page uses Taguchi orthogonal arrays, which are standard tables of tests. An array for the same experiment also takes 9 tests, but it changes several factors in each test. Every level appears in 3 tests, and the other factors are balanced across those tests, so you can compare averages to see the effect of each factor.

This method assumes that each factor affects the result independently. If the effect of one factor depends on the level of another factor, the result can be misleading.

Enter your factors

Replace the following example with your own factors. On each line, write the name of one factor, a colon, and then its levels, separated by commas. A factor can have 2 to 5 levels. The test plan updates as you type.

Temperature: 150, 175, 200
Pressure: low, medium, high
Catalyst: A, B, C

Run the tests

This page needs JavaScript to build the test plan.

  1. Do the tests in the following table in a random order. A random order keeps slow changes in your equipment from looking like the effect of a factor.
  2. For each test, set each factor to the level in its row, and then measure the result.
  3. Enter each result in the Score column.
  4. Download the test plan and your scores as a CSV file. The page saves nothing, so reloading the page clears your scores.

If a higher score is better, use the levels with the highest averages. If a lower score is better, use the levels with the lowest averages. Your plan might not include this combination, so do one more test with it to confirm the result.
